# Game vision

Chimp Hawk is a readable, expressive arcade skating game with a distinct character roster, graffiti identity and continuous street/transition lines. Controls should make it easy to start a line and reward deliberate timing, variety and recovery.

The current improvement cycle prioritizes correctness and consistency: keep earned points, teach the controls actually selected, preserve rider/board clarity, make recovery predictable, and keep feedback synchronized.

Preserve the user's accepted direction: keyboard/gamepad on PC; opposite-direction balance correction; persistent rail capture until bail, rail end or explicit jump; sharp stable cameras; Flip School first in tutorial; real skate Foley; reflective ORBIT; shared glow defaults **1.50 emissive / 1.09 bloom / .10 contribution / .11 radius**. Do not restore the rejected crowd cheer.

No new game mode, engine migration, new online/economy system, forced quality reduction or speculative asset replacement belongs to this cycle. Changes should strengthen the existing game and remain locally reviewable. [Profile](PROJECT_PROFILE.md) · [Roadmap](DEVELOPMENT_ROADMAP.md).
